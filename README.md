# カロリー記録（cal-log）

個人用の消費カロリー記録ツールです。次の8種目をカウンターで記録し、日付ごと・累計の消費カロリーを確認できます。

- 腹筋（1回 0.2 kcal）
- 背筋（1回 0.2 kcal）
- スクワット（1回 0.2 kcal）
- 舌回し（1カウント=20周 / 0.5 kcal・推定）
- おなかをへこませる（1分 2.0 kcal）
- ウォーキング（1セット=10分 / 37 kcal）
- 踏み台昇降（1セット=10分 / 50 kcal）
- ラジオ体操（第一）（1セット=約3分 / 13 kcal）

換算は体重60kg・METsベースの目安です。厳密な代謝測定ではありません。

## 使い方

1. GitHub Pages の URL をスマホのブラウザで開く
2. 「ホーム画面に追加」する
3. ＋/− で回数を記録する

データは端末の `localStorage` に保存されます（サーバーには送られません）。

## ホーム画面への追加

### iPhone（Safari）
1. 共有ボタンをタップ
2. 「ホーム画面に追加」

### Android（Chrome）
1. メニュー（⋮）を開く
2. 「ホーム画面に追加」または「アプリをインストール」

## ローカル確認

静的ファイルだけなので、任意の静的サーバーで開けます。

```bash
npx serve .
```

## カロリー換算について

体重60kgを想定し、国立健康・栄養研究所のMETs表などを参考にした目安です。

| 種目 | 根拠の目安 |
|------|------------|
| 腹筋・背筋 | 軽い〜中等度の自重筋トレ（約2.8〜3.8 METs）。100回≈4分で約12〜20kcal → 1回0.2kcal |
| スクワット | 自重・普通ペース（約3.0 METs・1回2秒前後）→ 1回約0.2kcal |
| 舌回し | 公的なMETs値なし。ごく軽い口腔運動として推定 |
| おなかをへこませる | 軽い体幹保持（約2.0 METs）→ 1分約2kcal |
| ウォーキング | 普通歩き（3.5 METs）10分 → 約37kcal |
| 踏み台昇降 | 台高約15cm（約4.7 METs）10分 → 約50kcal |
| ラジオ体操（第一） | 4.0 METs・約3分 → 約13kcal |

`app.js` の `EXERCISES` を編集すれば変更できます。
