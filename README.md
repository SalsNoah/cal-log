# カロリー記録（cal-log）

個人用の消費カロリー記録ツールです。次の6種目をカウンターで記録し、日付ごと・累計の消費カロリーを確認できます。

- 腹筋（1回 0.5 kcal）
- 背筋（1回 0.5 kcal）
- スクワット（1回 0.4 kcal）
- 舌回し（1カウント=20周 / 1.0 kcal）
- おなかをへこませる（1分 2.0 kcal）
- ウォーキング（1セット=10分 / 40 kcal）

## 使い方

1. GitHub Pages の URL をスマホのブラウザで開く
2. 「ホーム画面に追加」する
3. ＋/− で回数を記録する

データは端末の `localStorage` に保存されます（サーバーには送られません）。

## ホーム画面への追加

### iPhone（Safari）
1. 共有ボタンをタップ
2. 「ホーム画面に追加」

### Android（Chrome）
1. メニュー（⋮）を開く
2. 「ホーム画面に追加」または「アプリをインストール」

## ローカル確認

静的ファイルだけなので、任意の静的サーバーで開けます。

```bash
npx serve .
```

## カロリー換算について

目安値です。厳密な代謝計算ではなく、個人の記録用に設定しています。`app.js` の `EXERCISES` を編集すれば変更できます。
